# @percentsa/motion

Signature motion of the Percent Design System for React: text scramble, slash reveal, text rise, number roll, marquee, magnetic buttons, view cursor, counter and page transitions. Every part respects `prefers-reduced-motion`, works in right-to-left pages, and hides nothing when JavaScript is off.

```bash
bun add @percentsa/tokens @percentsa/motion
```

```css
@import "tailwindcss";
@import "@percentsa/tokens/theme.css";
@import "@percentsa/motion/styles.css";
```
